# دليل اللقاحات العراقي | Iraqi Vaccine Guide

نسخة تأسيسية أولية لموقع ويب متجاوب باللغة العربية (RTL)، ومهيأ ليصبح تطبيق ويب تقدمي PWA.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل محلياً
```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج
```bash
npm run build
npm run preview
```

## ما يتضمنه الهيكل الحالي
- واجهة عربية RTL متجاوبة للهاتف والحاسوب.
- قائمة الأقسام الرئيسية الاثني عشر.
- لوحة تحكم تأسيسية.
- إظهار حالة الاتصال بالإنترنت.
- إعداد PWA وService Worker للتخزين المؤقت الأولي.
- قاعدة IndexedDB محلية أولية لحفظ السجلات.

## ملاحظات مهمة
- هذه نسخة هيكل أساسي وليست نظاماً طبياً معتمداً أو جاهزاً للاستخدام السريري.
- بطاقات اللقاحات والجرعات والجداول ودرجات الحفظ لم تُملأ بعد؛ يجب اعتمادها من وزارة الصحة العراقية والبرنامج الوطني للتحصين.
- لا توجد بعد قاعدة مركزية أو تسجيل دخول أو مزامنة بين المراكز. ستضاف في مراحل لاحقة مع تصميم أمان وصلاحيات مناسب.
- لا تُدخل بيانات أطفال حقيقية في هذه النسخة التأسيسية.
